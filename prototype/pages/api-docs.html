无参数；成功后回调 /auth/github/callback 下发 httpOnly 会话 Cookie。
GET/users/me当前用户
200 OK · {"id":"u_001","github_login":"BaoXuebin","display_name":"BaoXuebin","email":"..."}

工作区与账本

GET/teams工作区列表
返回当前用户加入的工作区，含角色（owner / editor / viewer）与账本数。
POST/ledgers新建账本
Body：{"team_id","name","operating_currency":"CNY","start_date","opening_balances","is_bak"}。
GET/ledgers/{ledger_id}/revision当前修订号
200 OK · {"ledger_id":"...","revision":128}

账户

GET/ledgers/{ledger_id}/accounts?status=open账户列表
200 OK · [{"account":"Assets:Cash","type":"Assets","status":"open","opened_on":"2021-01-01",...}]
POST/ledgers/{ledger_id}/accounts开户（open 指令）
Body：{"account":"Assets:Bank:招商银行","opened_on":"2026-08-02","currency":"CNY","booking":"fifo"}。
POST/ledgers/{ledger_id}/accounts/{account}/balance期初对账（pad + balance）
Body：{"date":"2026-08-01","number":"12345.67"}；服务端写入 pad 与 balance 指令。

交易（命名遵循 beancount：narration / postings / units / cost）

GET/ledgers/{ledger_id}/transactions交易列表
Query：from / to / month / account / q / tag / limit / offset / order。
200 OK · {"items":[{"id":"txn-...","date":"2026-08-02","flag":"*","payee":"盒马鲜生","narration":"日常采购","tags":["Food"],"links":[],"postings":[{"account":"Expenses:Food","units":{"number":"-120.00","currency":"CNY"}},{"account":"Assets:Cash","units":{"number":"120.00","currency":"CNY"}}]}],"total":1}
POST/ledgers/{ledger_id}/transactions新建交易
Header：If-Revision-Match: 128；外币分录自动生成 cost / price。
Body：{"date":"2026-08-02","payee":"Starbucks","narration":"咖啡","tags":["Daily"],"postings":[{"account":"Expenses:Food:Coffee","units":{"number":"-38.00","currency":"CNY"}},{"account":"Assets:Cash","units":{"number":"38.00","currency":"CNY"}}]}
PUT/ledgers/{ledger_id}/transactions/{transaction_id}更新交易
整体替换；修订号不匹配返回 409 LEDGER_STALE。
GET/ledgers/{ledger_id}/transactions/{transaction_id}/raw交易原始 bean 文本
200 OK (text/plain) · 2026-08-02 * "盒马鲜生" "日常采购" #Food\n Expenses:Food 120.00 CNY\n Assets:Cash

统计 / 事件 / 源文件 / 导入

GET/ledgers/{ledger_id}/stats/account-trend?type=month账户趋势
type：day / month / year / sum。
GET/ledgers/{ledger_id}/stats/account-flow桑基图数据
200 OK · {"nodes":[{"name":"Expenses:Food"}],"links":[{"source":0,"target":1,"value":"120.00"}]}
POST/ledgers/{ledger_id}/events添加事件（event 指令）
Body：{"date":"2026-08-01","type":"工作","description":"入职新公司"}。
GET/ledgers/{ledger_id}/source-files/{path}读取源文件
path 为 URL 编码相对路径，如 month/2026-08.bean；写入前校验路径防穿越。
POST/ledgers/{ledger_id}/imports/{source}账单导入预览
source：alipay / wechat / icbc / abc；multipart 上传，返回带 AI 分类建议的预览行。

AI 与集成

POST/ledgers/{ledger_id}/ai/record自然语言记账
Body：{"text":"昨天星巴克咖啡 38 元"} 200 OK · {"draft":{"date":"2026-08-01","payee":"Starbucks","narration":"咖啡","postings":[...]},"notes":"AI 生成草稿，确认后调用交易创建接口"}
GET/ledgers/{ledger_id}/ai/insights洞察与异常检测
200 OK · {"insights":[{"type":"duplicate","message":"8 月 1 日与 2 日「盒马鲜生」各有 120.00 元扣款，疑似重复"}]}
POST/api-keys创建 API Key
Body：{"name":"claude-code","scope":"read-write"}；secret 仅返回一次（bgsk_ 前缀）。
POST/mcpMCP Server（Streamable HTTP）
供 Claude / Cursor 等 Agent 连接；工具：query_transactions / create_transaction / ai_record 等，Bearer API Key 认证。
完整契约以 packages/contracts/openapi.yaml 为唯一来源；前端类型与后端骨架由该文件生成
